# 資料作成のルール

人に見せる資料を作る作業のあいだ、次のルールに従う。プロジェクトに独自のルールがあれば、そちらを優先する。置き場所は `~/.claude/skills/00-kickoff/structure.md` に従い、標準構成でないプロジェクトではその構成に読み替える。

## 最初に確かめること

- 誰が、どの場面で見て、何を判断するための資料かを確かめる。わからなければ作る前に聞く

## 進め方

- 抽象的な構成案や選択肢を並べる前に、具体的な 1 枚や最小の実物を作って見せる。実物を見たほうが早く判断できるため
- プロジェクトに残す資料は、内容の正本を md(またはデータファイル)に置き、そこからスクリプトで生成する。スクリプトは `scripts/` に置く。内容の修正と見た目の修正を分けられ、作り直しが効くため。利用者に読んで確かめてもらうだけの報告は、共通ルールに従い、HTML に直接書く。md の正本を確かめてもらうときは、md をそのまま開かず、md から HTML を作って見せる
- 生成した資料を直接編集しない。直すときは正本かスクリプトを直して作り直す

## 道具

- 形式ごとの skill が導入されていれば使う(`pptx`、`xlsx`、`docx`、グラフは `dataviz`)
- 内容の文章を書く部分は `99-rules-documents` に従う
