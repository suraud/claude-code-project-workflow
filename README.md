# claude-code-project-workflow

Claude Code でプロジェクトを進めるためのスキル集です。プロジェクトの始め方、定期点検、作業の種類ごとのルールを、決まった形で揃えます。

## できること

<!-- 目指す姿。公開時に実際の機能に合わせて書き直す。 -->

- 新しいフォルダを、決まった構成のプロジェクトとして立ち上げる(目的の聞き取り、ひな形、git の初期化)
- プロジェクトが構成から外れていないかを定期的に点検する
- 文書、資料、コード、調査の作業で、守るルールを自動で読み込む
- 上のスキルを呼び出す共通ルール(`~/.claude/CLAUDE.md`)の見本を使える
